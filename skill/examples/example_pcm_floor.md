# Example: 相变电热地板低碳供暖

## 研究方向

模块化相变电热地板低碳供暖系统性能研究

## 创新点

基于模块化设计的相变电热地板，利用谷电蓄热实现低碳供暖，研究其热性能和运行控制策略。

## 选题分析要点

1. **研究对象**: 相变电热地板 (PCM electric heating floor)
2. **研究方法**: 实验 + 数值模拟
3. **应用场景**: 低碳建筑供暖 (low-carbon building heating)
4. **关键词歧义风险**:
   - `PCM` → 既可指 Phase Change Material (相变材料)，也可指 Pulse Code Modulation
   - 建议始终使用全称 `phase change material`
