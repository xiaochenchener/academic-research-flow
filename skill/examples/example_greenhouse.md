# Example: 双层日光温室热湿环境

## 研究方向

寒冷地区双层日光温室热湿环境动态模型

## 创新点

考虑太阳辐射传输、双层膜围护结构传热、保温被动态控制、土壤/墙体蓄放热、通风换气和湿量迁移的逐时热湿环境动态模型。

## 选题分析要点

1. **研究对象**: 双层日光温室 (double-layer solar greenhouse)
2. **研究方法**: 动态热湿耦合模型 (dynamic hygrothermal model)
3. **应用场景**: 寒冷地区温室生产 (cold region greenhouse production)
4. **关键词歧义风险**:
   - `greenhouse` → 易与 `greenhouse gas` / `greenhouse effect` 混淆
   - 建议搜索: `solar greenhouse` / `Chinese solar greenhouse` / `greenhouse thermal model`
